# Sudoku Web App 🧩

A web-based Sudoku game built with **Python, Flask, JavaScript, and HTML**, featuring difficulty selection and mistake tracking.

## Features
- Playable 9×9 Sudoku board
- Difficulty selection (Easy / Medium / Hard)
- Mistake counter (game over after 3 mistakes)
- Immediate input validation (correct cells turn green, bolded, and locked)
- Randomized puzzle generation per game

## Tech Stack
- Python (Flask)
- HTML & CSS
- JavaScript

## How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/loopsaloy/sudoku-web-app.git
```
2. Navigate into Project Directory:
```bash
cd sudoku-web-app
```
3. Run the application:
```bash
python app.py
```
4. open your browser and go to:
```bash
http://127.0.0.1:5000
```
